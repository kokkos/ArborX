Meaning of fields:

- Application: the name of an application
- Area: whats the application field (e.g. Molecular Dynamics, BioInformatics, CFD etc.)
- Institution: where is it getting developed
- Website: where to find more info on the project
- Status: what is the current status of progress

  - Production (i.e. runs science/engineering problems)
  - Experimental (integration of ArborX, not used for actual runs)
  - Evaluation (looking at using ArborX but no firm decision)
- Contact Name: who is the point of contact
- Contact Email: if someone has questions where to ask them
